# 🎨 Top 10 Moderných Webových Šablón a UI Knižníc

Zoznam najlepších zdrojov moderného dizajnu (Next.js, React, Tailwind CSS, shadcn/ui):

### 1. shadcn/ui
- **Web:** https://ui.shadcn.com/
- **Popis:** Základný priemyselný štandard. Celé bloky stránok, dashboardy, formuláre a autentifikácia.

### 2. Magic UI
- **Web:** https://magicui.design/
- **Popis:** Špičkové animácie, žiariace karty, lúče na pozadí, plávajúce doky a startup šablóny.

### 3. Aceternity UI
- **Web:** https://ui.aceternity.com/
- **Popis:** Futuristické 3D karty, Aurora svetelné efekty a Apple-style vizuálne prvky.

### 4. 21st.dev
- **Web:** https://21st.dev/
- **Popis:** Komunitná platforma najlepších komponentov z v0.dev a Reactu.

### 5. Origin UI
- **Web:** https://originui.com/
- **Popis:** Detailné a precízne vyladené tlačidlá, vstupné polia a interaktívne ovládacie prvky.

### 6. Cruip
- **Web:** https://cruip.com/
- **Popis:** Kompletné hotové landing pages a SaaS šablóny pre Next.js & Tailwind.

### 7. Tremor / Tremor Raw
- **Web:** https://www.tremor.so/ | https://raw.tremor.so/
- **Popis:** Najkrajšie analytické grafy, štatistické nástenky a klientske zóny.

### 8. HyperUI
- **Web:** https://www.hyperui.dev/
- **Popis:** Veľká zbierka čistých Tailwind komponentov, cenníkov a pätičiek.

### 9. Godly Website
- **Web:** https://godly.website/
- **Popis:** Denná kurátorovaná galéria najkrajších živých webov sveta pre inšpiráciu.

### 10. Land-book
- **Web:** https://land-book.com/
- **Popis:** Databáza najlepších landing pages a osobných portfólií na internete.
